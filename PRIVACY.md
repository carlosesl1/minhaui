# Privacy

Obsidian Glass is local-first. It does not require an account, does not include advertising, and does not send telemetry by default.

- Settings, themes, logs, and diagnostics remain on the current computer unless the user explicitly exports a file.
- Weather and other optional network providers stay disabled until the user enables one and sees which data it needs.
- Diagnostics are redacted before export and are never uploaded automatically.
- Imported themes are treated as data, cannot execute code, and are checked for size, schema, checksum, and unsafe paths.

Commercial releases must publish the exact provider list and contact address before distribution.
